## 2. Masalah yang muncul
- **Issue**: Terjadi *Database is locked* pada SQLite saat menjalankan `migrate:fresh --seed`.
  - **Status**: Solved
  - **Solusi**: Mematikan sementara proses `php artisan serve` yang mengunci koneksi database sebelum menjalankan ulang migrasi.
- **Issue**: Git pull di server mengalami konflik *untracked files* (Livewire/Flux assets).
  - **Status**: Solved
  - **Solusi**: Menghapus folder duplikat di server (`rm -rf public/flux public/vendor/livewire`) lalu menjalankan `git pull origin main` kembali.
- **Issue**: Tombol submit/create tidak merespons klik dan muncul error console `Cannot read properties of null (reading 'localName')`.
  - **Status**: Solved
  - **Solusi**: Mengganti tag HTML raw `<button>` di dalam `<flux:dropdown>` pada `sidebar.blade.php` dengan komponen resmi `<flux:button>`.
- **Issue**: Checkbox pilihan role di form user tidak bisa dicentang.
  - **Status**: Solved
  - **Solusi**: Mengganti pembungkus manual dengan `<flux:checkbox.group wire:model="selected_roles">` sesuai spesifikasi Flux UI.

## 3. Yang gw pelajarin
- **Insight**: Komponen web kustom [[Flux UI]] membutuhkan hierarki tag spesifik (seperti `flux:button` di dalam `flux:dropdown` dan `flux:checkbox.group` untuk array Livewire) agar lifecycle Javascript tidak mengalami runtime crash.
- **Keputusan**: Role [[Asatidz]] diberikan akses monitoring data penting (santri & keuangan) tanpa izin merubah data atau mencetak laporan kas keluar/masuk untuk menjaga integritas data keuangan institusi.
