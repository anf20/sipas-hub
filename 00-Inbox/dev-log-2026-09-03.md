# Dev Session Log - 2026-09-03

## 1. Apa yang dibangun hari ini
- Membuat fitur "Wizard Inisialisasi Sistem Akademik" (5 steps) yang digunakan untuk melakukan setup massal awal tahun ajaran baru atau dari blank state.
- Implementasi dual input: Entri manual satu per satu & Upload massal (Excel/CSV) di setiap step menggunakan *template* download dinamis.
- Implementasi UI interaktif: Validasi *inline*, revisi data error langsung di table (tanpa perlu upload ulang seluruh file Excel), dan table *preview* data yang *valid*.
- Membuat `AcademicInitializationService` untuk menyimpan data `AcademicYear`, `SchoolClass`, staff `User`, `Student` beserta relasi ortunya (`User`), dan `FeeType` dalam satu blok `DB::transaction`.
- Auto-generate tagihan SPP selama 12 bulan untuk tiap siswa (terjadwal setiap tanggal 10 awal bulan) yang disesuaikan dengan nominal SPP spesifik murid, serta generator untuk tagihan non-SPP dan tunggakan dari tahun sebelumnya.
- Integrasi *sidebar menu* dan *routing* agar bisa diakses oleh `Super Admin` dan `Admin Akademik`.

## 2. Masalah yang muncul
- **Issue**: Error `View [livewire.pages.academic.partials.wizard-import-section] not found` saat mengakses halaman `/academic/initialization-wizard`.
  - **Status**: Solved.
  - **Solusi**: File template blade utama untuk wizard terlalu panjang, sehingga modul *import section* & *tables* dipisahkan dengan `@include`. Error muncul karena file blade *partials* (termasuk *invalid table* dan *valid table*) belum terbuat saat *livewire component* dirender. Solusinya dengan menuntaskan pembuatan file-file partial tersebut di direktori `resources/views/livewire/pages/academic/partials/`.

## 3. Yang gw pelajarin & Keputusan Teknis
- **Insight**: Menggunakan struktur validasi ganda. *Parser Service* dapat menangani array *raw data* yang datang baik dari file *Excel import* (`Maatwebsite\Excel`) maupun array manual *form submit*.
- **Keputusan**: Tetap memisahkan class *Student* dan modul operasional reguler dengan wizard. *Wizard* difokuskan sebagai "one-off transactional tool", sehingga resiko merusak modul harian sangat minim. Pembuatan fitur ini direkam di [[Academic-Initialization-Wizard]].
