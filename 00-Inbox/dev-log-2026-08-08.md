# Dev Session Log - 2026-08-08

## 1. Apa yang dibangun hari ini
- Fitur unggah bukti transfer manual di portal detail tagihan (`InvoiceDetail.php`) dan massal (`Invoices.php`) oleh Orang Tua.
- Integrasi tombol redirect otomatis ke WhatsApp Admin Keuangan dengan pre-filled text dinamis berisi rincian tagihan.
- Halaman **Verifikasi Pembayaran** bagi Admin Keuangan (`PaymentVerification.php`) untuk menyetujui (ubah status ke success, generate kwitansi resmi `SCH-YYYYMM-XXXX`, kirim WA konfirmasi) atau menolak (revert status ke unpaid, input alasan penolakan, kirim WA notifikasi).
- Mekanisme **Kompresi Bukti Transfer ke WebP** (kualitas 75%) menggunakan GD library dengan output buffering agar hemat ruang disk server.
- Fitur interaktif **Salin Nomor Rekening** BSI menggunakan Alpine.js.
- Pemisahan popup alur pembayaran: modal ringkasan hanya berisi pilihan pembayaran, lalu modal transfer manual baru yang memuat formulir uploader bukti transfer.
- Redesain layout card tagihan di Dashboard (`dashboard.blade.php`) & Daftar Tagihan (`invoices.blade.php`) menjadi 2 kolom (logo di kiri, konten di kanan) & 3 baris (Judul, Detail, dan Nominal-Badge sejajar di pojok bawah).
- Pembaruan UI halaman **Riwayat Pembayaran** (`History.php` & `history.blade.php`): meletakkan tombol filter lanjutan di ujung kiri sejajar dengan scrollable horizontal month pills, menghapus kolom pencarian, serta memindahkan dropdown Kategori dan Tahun ke bagian bawah filter bulan.
- Penyelarasan layout list **Riwayat Tagihan** agar seragam dengan Dashboard dan Daftar Tagihan (menggunakan layout 2 kolom dan 3 baris dengan nominal di kiri bawah serta aksi/badge di kanan bawah).
- Setup [[Cloudflare Tunnel]] (`sipas-lokal`) dengan model dashboard-managed menggunakan token untuk mengamankan koneksi server lokal Laravel ke internet.
- Konfigurasi `cloudflared` sebagai service Windows di Command Prompt Administrator agar tunnel dapat berjalan otomatis secara permanen di background.
- Tes fungsional lengkap di `PaymentVerificationTest.php` untuk memvalidasi seluruh alur.

## 2. Masalah yang muncul
- **Issue**: Admin keuangan tidak bisa memuat gambar bukti transfer dari server lokal.
  - **Status**: Solved
  - **Solusi**: Dibuat link simbolik folder penyimpanan dengan mengeksekusi `php artisan storage:link` sehingga path `/public/storage` mengarah ke folder asli `/storage/app/public`.
- **Issue**: Kolom `students` tidak memiliki kolom `nisn` saat seeder berjalan di SQLite memory.
  - **Status**: Solved
  - **Solusi**: Memperbaiki typo pemanggilan kolom `nisn` menjadi `nis` dan mengubah status dari `active` menjadi `aktif` di `TestDatabaseSeeder.php`.
- **Issue**: File upload GD path break di automated test karena database menggunakan Storage Fake.
  - **Status**: Solved
  - **Solusi**: Mengganti penulisan file fisik lokal `storage_path` menjadi output buffering string, lalu disimpan melalui `Storage::disk('public')->put()`.
- **Issue**: Gagal otorisasi CLI `cloudflared tunnel login` karena kendala timeout pengunduhan sertifikat `cert.pem`.
  - **Status**: Solved
  - **Solusi**: Migrasi menggunakan mode dashboard-managed tunnel di Cloudflare Zero Trust, sehingga otorisasi cukup memakai token tanpa perlu mengunduh file sertifikat fisik.
- **Issue**: Terjadi bentrok DNS record saat mendaftarkan hostname `sipashub.my.id` di dashboard tunnel.
  - **Status**: Solved
  - **Solusi**: Menghapus DNS record (A/CNAME) lama yang tidak terpakai di dashboard Cloudflare agar DNS routing tunnel bisa terbuat secara otomatis.
- **Issue**: Error `DNS_PROBE_FINISHED_NXDOMAIN` saat mengakses domain.
  - **Status**: Open
  - **Solusi**: Menunggu proses propagasi nameserver Cloudflare yang baru saja diubah di penyedia domain (IDCloudHost).

## 3. Yang gw pelajarin
- **Insight**: Melakukan manipulasi gambar GD di Laravel lebih aman dilakukan dengan menangkap binary stream menggunakan output buffering (`ob_start()`), agar tetap kompatibel dengan mock test `Storage::fake()` dan integrasi cloud storage (S3).
- **Insight**: Mengelola tunnel lewat Dashboard Cloudflare jauh lebih praktis dan minim error izin akses file dibanding metode CLI manual, karena hanya membutuhkan satu token string untuk instalasi service.
- **Keputusan**: Alur pembayaran di portal Orang Tua sengaja didelegasikan menjadi dua modal bertahap agar UI pemilihan metode pembayaran tetap bersih dan uploader file baru tampil jika metode transfer manual dipilih.
